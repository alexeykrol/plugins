# Plugin marketplace backlog

Owner's decisions and ideas of 09.11.2026. Order of work: first a novice goes through the installation path of
`kb` via GitHub, then the storefront.

## Accepted

- **GitHub is a warehouse, not a store.** Plugins are downloaded from here; a novice does not come here — GitHub
  scares them, the README does not sell (owner's word 09.11).
- **The store is a website:** one storefront with plugin cards, each plugin has its own landing page.
  The page sells even when the plugin is free: why it exists, what you get, an example, terms, how to
  install it.
- **Social media posts lead to the plugin page**, rather than retelling the installation commands.
- **One repository `alexeykrol/plugins` for all systems** — sections `claude-code/`, `codex/`,
  `bots/`. A name not tied to Claude (owner's word 09.11).
- **First our own marketplace, then an application to the official Anthropic marketplace** — the application = publication,
  only on the owner's "yes".

## Where the plugin works — reconnaissance of Anthropic documentation (09.11)

| App mode | Where it takes plugins from | How to install | Local base server (MCP) |
|---|---|---|---|
| Code, terminal, VS Code | the shared `~/.claude` folder on the Mac — one installation for all three | `claude plugin marketplace add …` or "+ → Add plugins" | works |
| Cowork | claude.ai account (not `~/.claude`) | Customize → Plugins → Add → Add marketplace | only if the session is on the computer |
| Chat | claude.ai account | same | **does not start**, only skills work |
| Browser | claude.ai account | same | does not start |

Consequences:
- **Base and search live inside the skill** (a script on standard Python + the base file), MCP is only
  an additional path. Then one plugin answers in Chat, Cowork and Code.
- **The plugin root must not have a `bin/` folder** — with it Chat and Cowork do not install the plugin.
- **A private repository in Chat/Cowork** requires granting the Claude app access on GitHub (Claude
  GitHub App). There is an open bug report: a private marketplace cannot be added in Cowork, while in
  the terminal it works (claudeissues #28125, a third-party source). Check in a test.
- **The user's "what is correct" answers are not kept in Chat** between conversations (sandbox). Memory in Chat
  requires a remote server — that is a different architecture, a separate decision.
- **A plugin installed from the terminal does not get into the claude.ai account** — for Chat/Cowork it is
  installed separately via Customize. The plugin page has two installation paths.

Sources: [Claude Code Desktop](https://code.claude.com/docs/en/desktop.md),
[installing plugins](https://code.claude.com/docs/en/plugins/install.md),
[platform support](https://claude.com/docs/plugins/platform-support.md),
[plugins in Claude](https://support.claude.com/en/articles/13837440-use-plugins-in-claude).
