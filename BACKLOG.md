# Бэклог магазина плагинов

Решения и идеи владельца 09.11.2026. Порядок работ: сначала новичок проходит путь установки
`kb` через GitHub, потом витрина.

## Принятое

- **GitHub — склад, а не магазин.** Отсюда плагины скачиваются; новичок сюда не ходит — GitHub
  его пугает, README не продаёт (слово владельца 09.11).
- **Магазин — сайт:** одна витрина с карточками плагинов, у каждого плагина своя страница-лендинг.
  Страница продаёт, даже когда плагин бесплатный: зачем он, что получите, пример, условия, как
  поставить.
- **Посты в соцсетях ведут на страницу плагина**, а не пересказывают команды установки.
- **Один репозиторий `alexeykrol/plugins` на все системы** — разделы `claude-code/`, `codex/`,
  `bots/`. Имя без привязки к Claude (слово владельца 09.11).
- **Сначала свой магазин, потом заявка в официальный магазин Anthropic** — заявка = публикация,
  только по «да» владельца.

## Ошибки приложения Claude (общие для всех плагинов)

- [ ] **Chat/Cowork не подтягивают новую версию сами** (находка владельца 09.11): через 16 минут
  после выкладки 0.3.1 приложение показывало 0.3.0. На странице плагина нужен шаг «как обновить»
  (Customize → Plugins → магазин → Обновить; иначе удалить и добавить заново). Обещание
  «обновления приходят сами» для Chat/Cowork пока неверно.
  10.11, плагин pen: приложение не увидело новый плагин в магазине вообще. Обходной путь — Claude Code
  собирает файл `<плагин>.plugin` (zip плагина), его ставят в приложении вручную; после установки файл
  не нужен (плагин живёт в системной папке Claude). Штатный путь — магазин сам видит новое.

## Где работает плагин — разведка по документации Anthropic (09.11)

| Режим приложения | Откуда берёт плагины | Как поставить | Локальный сервер базы (MCP) |
|---|---|---|---|
| Code, терминал, VS Code | общая папка `~/.claude` на Mac — одна установка на все три | `claude plugin marketplace add …` или «+ → Add plugins» | работает |
| Cowork | аккаунт claude.ai (не `~/.claude`) | Customize → Plugins → Add → Add marketplace | только если сессия на компьютере |
| Chat | аккаунт claude.ai | то же | **не запускается**, работают только навыки |
| Браузер | аккаунт claude.ai | то же | не запускается |

Следствия:
- **База и поиск — внутри навыка** (скрипт на стандартном Python + файл базы), MCP — только
  дополнительный путь. Тогда один плагин отвечает в Chat, Cowork и Code.
- **В корне плагина не должно быть папки `bin/`** — с ней Chat и Cowork плагин не ставят.
- **Закрытый репозиторий в Chat/Cowork** требует дать доступ приложению Claude на GitHub (Claude
  GitHub App). Есть открытое сообщение об ошибке: закрытый магазин в Cowork не добавляется, а в
  терминале работает (claudeissues #28125, сторонний источник). Проверить в тесте.
- **Ответы пользователя «что верно» в Chat не сохраняются** между разговорами (песочница). Для
  памяти в Chat нужен удалённый сервер — это уже другая архитектура, отдельное решение.
- **Плагин, поставленный из терминала, в аккаунт claude.ai не попадает** — для Chat/Cowork его
  ставят отдельно через Customize. На странице плагина — два пути установки.

Источники: [Claude Code Desktop](https://code.claude.com/docs/en/desktop.md),
[установка плагинов](https://code.claude.com/docs/en/plugins/install.md),
[поддержка по платформам](https://claude.com/docs/plugins/platform-support.md),
[плагины в Claude](https://support.claude.com/en/articles/13837440-use-plugins-in-claude).

## Установка для новичка — открытые вопросы

- [ ] **Где новичок работает.** Большинство — в приложении Claude Desktop. Проверить в нём три
  пути и выбрать главный для страницы:
  1. вкладка **Code**: вставить готовый промпт — Claude сам выполнит установку;
  2. режим **Cowork**: Настроить → Плагины → «Добавить магазин из GitHub» — мышкой. Весной 2026
     были сообщения, что плагины из сторонних магазинов пропадают после перезапуска — проверить
     на текущей версии;
  3. терминал Claude Code — для тех, кто им пользуется.
- [ ] **Python на чистом Mac.** Первый запуск `python3` может открыть окно установки
  инструментов разработчика Apple. Описать на странице со скриншотом.
- [ ] **Браузерный Claude не поддерживается:** плагин работает с файлами на компьютере. Писать
  первой строкой страницы. Путь для браузера — база в интернете (позже, идея владельца 06.11).
