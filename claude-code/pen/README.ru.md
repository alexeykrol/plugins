# pen — редактор постов

**Для тех, кто думает и пишет на своём языке, но хочет, чтобы его услышали на английском** — в X,
LinkedIn и других соцсетях.

## Для кого

Эксперты, основатели, авторы и профессионалы, для которых английский не родной. Лучше всего вы
пишете на своём языке: там ваши мысли точные. А аудитория, клиенты и возможности — в
англоязычных X и LinkedIn.

## Какие проблемы решает

**1. Перевод, который сохраняет смысл.** Машинный перевод даёт английский, который формально
правильный, но говорит другое: тезисы смягчаются, идиомы превращаются в бессмыслицу, ваш голос
пропадает. pen сначала переводит смысл, потом переписывает его естественным американским
английским и построчно проверяет, что ни один тезис не потерялся и не ослаб.

**Ваш голос остаётся вашим.** pen убирает шум, а не характер. Если вы пишете резко,
провокационно или крепкими словами — это ваш выбор: pen не сглаживает, не смягчает, не
добавляет оговорок и не учит вас тону. Мат переводится равным по силе английским, сарказм
остаётся сарказмом.

**2. Сырые черновики и голосовые заметки.** Многие надиктовывают мысли. В расшифровке —
слова-паразиты, повторы, ошибки распознавания. pen сначала превращает её в чистый письменный
пост на вашем языке, который можно публиковать как есть.

**3. Лимит LinkedIn — 3000 знаков.** pen вписывает текст в лимит: сначала убирает связки и
повторы, ваши мысли — в последнюю очередь. Если без потери мысли не влезает — делит на части
Part 1/2, Part 2/2, а не выбрасывает содержание. Полный текст вы тоже получаете — его можно
опубликовать как статью LinkedIn.

**4. X без Premium.** В бесплатном аккаунте X пост ограничен 280 знаками. pen даёт один
английский текст, уже разбитый на пронумерованные блоки до 280 знаков: с Premium вставляете
целиком, без него — публикуете по блокам тредом. Блоки совпадают с вашими пунктами, поэтому
тред читается как логическая последовательность.

**5. Вставка без поломанной вёрстки.** Текст, скопированный из чата, часто теряет нумерацию.
pen выдаёт каждый текст блоком простого текста с кнопкой **Copy**: нумерация и переносы строк
сохраняются при вставке в LinkedIn и X.

## Что вы получаете

Напишите `/pen:tren` и вставьте пост (или приложите файл). Вы получите три текста:

1. **На вашем языке** — исправленный оригинал, готовый для вашей родной аудитории.
2. **X** — полная версия на американском английском, разбитая на блоки треда до 280 знаков.
3. **LinkedIn** — английская версия в пределах 3000 знаков (или по частям, если без потери
   мысли не влезает).

Плюс несколько заметок: что почищено, как переведены трудные идиомы, что сокращено, и более
сильная первая строка, если ваша слабая.

Нужна только корректура, без перевода? `/pen:corr`.

Писать можно на любом языке: язык исходника определяется по тексту, перевод всегда на
американский английский. Заметки и вопросы плагин пишет на том языке, на котором вы пишете
Claude. Корректура лучше всего работает на распространённых языках, на редких качество ниже.
Длина считается скриптом, для лимита 280 — по правилам самого X.

**Посмотреть в деле:** мои английские посты в X написаны с помощью pen —
[@old_alexeykrol](https://x.com/old_alexeykrol). Сравните с тем, что даёт машинный переводчик.

**Что нужно:** приложение Claude для компьютера (<https://claude.ai/download>) и платная
подписка Claude.

**Приватность:** работает только с текстом, который вы ему дали. В интернет ничего не
отправляет, ваших файлов не трогает.

## Установка

Магазин: `alexeykrol/plugins`.

> **Не просите Claude в чате «выполнить команды установки».** В чате у Claude свой временный
> облачный компьютер: плагин встанет туда и пропадёт после разговора.

### Путь 1. Chat и Cowork

1. В приложении Claude откройте меню слева → **Customize** (Настроить) → **Plugins** (Плагины).
2. **Add** → **Add marketplace** (Добавить магазин), введите `alexeykrol/plugins`. Если магазин
   уже добавлен — пропустите этот шаг.
3. **Пока магазин закрытый:** приложение попросит подключить GitHub — согласитесь и дайте доступ
   к репозиторию `alexeykrol/plugins`.
4. В списке плагинов найдите **pen** и нажмите **Install** (Установить).
5. Начните **новый разговор** и напишите `/pen:tren`, затем вставьте текст поста.

### Путь 2. Code (вкладка Code в приложении, терминал, VS Code)

Создавая сессию во вкладке Code, выберите запуск **на этом компьютере (Local)**, а не в облаке.

```
/plugin marketplace add alexeykrol/plugins
/plugin install pen@krol
```

Или из терминала:

```
claude plugin marketplace add alexeykrol/plugins
claude plugin install pen@krol
```

После установки перезапустите сессию.
