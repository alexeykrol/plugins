# Плагины для Claude

Работают в приложении Claude (Chat, Cowork, Code), в терминале и в VS Code.
Каждый плагин — в своей папке, у каждого своя инструкция.

| Плагин | Для чего | Инструкция |
|---|---|---|
| **BestMentor** (`bestmentor`) — книга «Теория каст и ролей» | Claude отвечает по книге: глава, цитата, «в книге этого нет» | [bestmentor](bestmentor/README.md) |
| **pen** — редактор постов | Корректура текста и расшифровок на любом языке, перевод на американский английский, версии для X и LinkedIn | [pen](pen/README.ru.md) |
