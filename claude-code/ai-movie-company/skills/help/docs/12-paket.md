# Набор для анимации (дополнения)

## Что он даёт

С набором ролики могут выглядеть как у больших блогеров:

- **живые титры у рилсов** — по 2–3 слова, произносимое слово подсвечивается цветом (когда
  время слов известно по голосу; иначе фраза показывается целиком);
- **нарисованные карточки** в начале и в конце ролика, с движением, и **обложка**;
- **видео из текста** — сцены рисуются кодом;
- позже — **объёмная заставка** в начале.

Без набора записи всё равно читаются, фрагменты выбираются, ролики режутся и загружаются — просто
оформление остаётся обычным: ровные белые строчки и простые карточки. Быстрее от набора плагин не
становится: он добавляет вид, а не скорость.

## Как он ставится

Обычно — **сам, вместе с плагином**: тот же один промпт установки ставит и набор. Это добавляет
к установке пару минут.

Если при установке что-то не скачалось (пропал интернет, сайт не ответил), плагин всё равно
работает, а проверка компьютера покажет, чего не хватает. Тогда просто скажите мне:
**«установи дополнения»** — я поставлю только недостающее, уже скачанное второй раз не качается.

После того как поставился плагин Remotion для Claude, Claude нужно перезапустить — я предложу кнопку
«Перезапустить Claude» и сделаю это сама: окно закроется на несколько секунд и откроется снова.

## Что внутри и откуда

| Что | Зачем | Откуда | Скачать |
|---|---|---|---|
| **Node.js** 24 | запускает инструменты, которые рисуют ролик | nodejs.org — официальный сайт Node.js | ≈28 МБ |
| **Chrome Headless Shell** 158 | Chrome без окон, сделанный для отрисовки видео: кадры рисуются в нём невидимо | Google, Chrome for Testing | ≈105 МБ |
| **Проект Remotion** | сами инструменты рисования | npm, по закреплённому списку версий | ≈270 МБ на диске |
| **Плагин Remotion для Claude** | подсказки Claude, как рисовать видео кодом (только тексты, без программ) | каталог плагинов Anthropic, встроенный в Claude | мало |

Вместе — около **130 МБ** загрузки и около **700 МБ** на диске.

## Почему это безопасно

- Всё берётся только с официальных адресов. У каждого скачиваемого файла заранее записан его
  отпечаток: если скачалось что-то другое, установка останавливается и ничего не ставится.
- Версии инструментов рисования закреплены и не моложе двух недель — свежие выпуски, в которых
  чаще всего прячут вредный код, не берутся. Установочные скрипты пакетов не запускаются.
- Всё ложится в папку плагина (`~/.ai_video_pipeline/extras` и `~/.ai_video_pipeline/remotion`).
  Пароль не нужен, системные настройки, другие программы и ваш обычный Chrome не трогаются.
- Удалить — значит удалить эти папки.

## Ограничения

- Набор сделан для Mac. На Mac с процессором Intel плагин пока не ставится.
- Для установки нужен интернет; дальше рисование работает без сети.
