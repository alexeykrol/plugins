# Доделать ролик руками в CapCut

Кроме YouTube, плагин умеет сделать **проект для CapCut** (настольная программа для Mac) — для
каждого готового ролика свой. Его можно открыть и поправить руками: подрезать, сдвинуть, поменять
шрифт или текст субтитров, добавить музыку.

## Что внутри проекта

- **Дорожка видео** — нарезка ролика (без заставок в начале и в конце, без субтитров в кадре).
- **Дорожка текста** — вычитанные субтитры, по одному кусочку текста на каждую реплику. Каждый
  кусочек редактируется как обычный текст в CapCut; стиль можно поменять сразу всем.
- **Кадр** — вертикальный 1080×1920 для рилсов, горизонтальный 1920×1080 для длинных роликов.

Название проекта — «<папка задания> <номер ролика>», например «2026-11-16-lekciya r01». Новый
проект появляется вверху списка проектов CapCut.

## Как получить

Когда ролики из записи готовы и показаны, Эльза один раз сама предложит кнопкой **«Собрать проект
CapCut»** — можно отказаться («Не нужно»). И в любой момент можно попросить в чате: «сделай проект
для CapCut» (можно назвать ролик: «для r01»). У видео из текста проект CapCut делается всегда, сам.

Сам CapCut вы ставите себе сами (он бесплатный). Есть ли он на компьютере, Эльза проверяет
заранее — для видео из текста ещё до начала работы — и, если его нет, говорит об этом сразу:
можно продолжить без проекта CapCut или сначала поставить программу.

Что вы потом поправите в CapCut руками, Эльза не видит. Если хотите, чтобы она это учла, —
расскажите ей словами, что поменяли и почему.

**CapCut должен быть закрыт.** CapCut переписывает свой список проектов при выходе и
стёр бы новый проект. Если CapCut открыт, плагин ничего не пишет и предлагает кнопки «Закрыть CapCut
за меня» / «Закрою сама» — Эльза закроет его сама, ничего нажимать на клавиатуре не нужно.

## Заставка перед роликом

Можно поставить перед роликом свою заставку (титры, логотип) — в том же проекте. Попросите:
«сделай проект для CapCut с заставкой <файл>». Режиссёр запустит
`vp capcut export <задание> r01 --opener <заставка.mp4>`.

- Заставка идёт с самого начала, за ней — ролик; переход между ними — плавное растворение
  0,8 секунды (`--dissolve 0.5` — короче, `--dissolve 0` — без перехода, встык).
- Ролик, его звук и субтитры сдвигаются на длину заставки — субтитры остаются точно под речью.
- Если форма кадра у заставки другая (горизонтальная заставка перед вертикальным рилсом), она
  **не растягивается**: вписывается целиком, сверху и снизу (или по бокам) — чёрные поля.
- Если в заставке нет звука, плагин подкладывает тишину.
- Плагин пишет, что он сделал с заставкой: размер, поля, звук, переход.

Растворение «впечатано» в сам файл заставки (последние 0,8 секунды заставки уже показывают начало
ролика), а не сделано переходом CapCut. Поэтому заменить переход другим в CapCut нельзя — можно
только пересобрать проект с другим `--dissolve`. Название такого проекта — «… r01 opener».

## Что плагин не трогает

- Чужие проекты CapCut — никогда не меняет, не двигает и не удаляет. В свой проект видео из текста
  он только добавляет новый таймлайн; прежние таймлайны не трогает.
- Список проектов CapCut перед изменением сохраняется копией в `~/.ai_video_pipeline/capcut/backups/`.
- Повторный экспорт не перезаписывает прежний проект — появится новый, «… r01 2».
- Для видео из текста — один проект на задание, а каждая версия — новый таймлайн в нём: «v1 — …»,
  «v2 — …» … Ваши ручные правки в прежних таймлайнах остаются как были (см. `10-tekst-v-video.md`).
  Перед добавлением версии служебные файлы проекта копируются в
  `~/.ai_video_pipeline/capcut/backups/`.

## Ограничения

- Формат проекта CapCut нигде не описан; плагин повторяет то, что пишет **CapCut 9.8.0 на Mac**.
  Другая версия CapCut может такой проект не открыть — тогда скажите об этом, формат обновят.
- Нарезка **копируется** внутрь проекта CapCut (CapCut на Mac не может читать файлы вне своей папки
  «Фильмы», если вы не выбрали их сами). Поэтому проект не зависит от папки задания, но занимает
  место: столько же, сколько сам ролик. Для рилса это десятки мегабайт, а для **целой лекции —
  гигабайты** в папке «Фильмы»: ненужные проекты удаляйте в самом CapCut.
- Плагин проверяет версию CapCut: формат взят из **9.8.0**. Если у вас другая, он предупредит —
  проект может не открыться.
- Готовое видео с заставками и субтитрами в кадре (`render.mp4`) в проект не попадает: в CapCut
  собирается ваша версия ролика.
