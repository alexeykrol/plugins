# Доделать ролик руками в DaVinci Resolve или Final Cut Pro

Если вы монтируете сами, плагин может отдать ролик **черновой сборкой** — монтажным листом, где
каждый слой отдельно и правится руками. Поправили, вывели готовый файл — дальше можно вернуть его
режиссёру на публикацию (это пока в планах, см. ниже).

## Что внутри

Для каждого готового ролика — папка `<задание>/exports/edit/<ролик>/`:

- **`<задание> <ролик>.fcpxml`** — монтажный лист (формат FCPXML 1.10). На нём:
  - заставка в начале, нарезка, заставка в конце — три отдельных клипа подряд;
  - звук нарезки — своей дорожкой под видео;
  - тексты заставок — отдельными **титрами** над заставками: текст можно переписать, шрифт и
    место поменять;
  - кадр — вертикальный 1080×1920 для рилсов, горизонтальный 1920×1080 для длинных роликов;
    частота кадров — как у записи.
- **`<ролик>.srt`** — вычитанные субтитры, уже по времени этого монтажного листа (с учётом
  заставки в начале).
- **`cards/`** — фон заставок (видео нужной длины в цвете канала, с тишиной).

Нарезка не копируется: лист ссылается на `clips/<ролик>/cut.mp4` в папке задания. Не переносите
и не удаляйте папку задания, пока работаете над роликом.

## Как получить

Попросите в чате: «сделай монтажный лист для DaVinci» (или «для Final Cut»). Режиссёр запустит
`vp resolve export <задание> [ролики]`. Повторный вывод не затирает прежний — появится новая папка
«<ролик> 2».

Вариант «как опубликовано»: `--baked-cards` берёт заставки из готового ролика (`render.mp4`) — с
текстом и подписью канала прямо в кадре, без отдельных титров.

## Как открыть в DaVinci Resolve (проверено на 19.1, Mac)

1. Создайте проект или откройте свой.
2. **File → Import → Timeline…** — выберите `.fcpxml`. Resolve сам найдёт видео по путям.
   Если спросит про настройки — оставьте настройки из файла: тогда кадр будет вертикальным.
3. Субтитры: **File → Import → Subtitle…** — выберите `.srt`, потом перетащите его из медиапула
   на таймлайн в самое начало (00:00:00:00). Появится дорожка субтитров, каждую реплику можно
   править.

Субтитры отдельным файлом, а не внутри `.fcpxml`, нарочно: субтитры внутри FCPXML Resolve и
Final Cut понимают по-разному, а `.srt` загружается одинаково везде.

## Как открыть в Final Cut Pro

**File → Import → XML…** — выберите `.fcpxml`; субтитры — **File → Import → Captions…** → `.srt`.
Final Cut Pro у нас не установлен, поэтому этот путь **не проверен** — если что-то не откроется,
скажите режиссёру.

## Чего пока нет

- **Подпись канала** поверх нарезки и **субтитры в кадре** у рилсов — их рисует только готовый
  ролик (`render.mp4`); в листе субтитры — отдельной дорожкой, а подписи канала нет.
- **Возврат готового файла.** Скоро можно будет сказать режиссёру «вот мой вариант» — ваш файл
  встанет вместо его ролика и пойдёт на описание, загрузку и одобрение как обычно. Пока этого нет.
- **Camtasia** — в планах.
