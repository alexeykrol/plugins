# AI Movie Company — условия использования

> **ЧЕРНОВИК для владельца, версия `2026-11-19-draft`.** Составлен агентом разработки по коду
> плагина и лицензии MIT; юрист его не читал. Прежде чем на него полагаться, покажите юристу —

> не ограничивает её; при расхождении действует LICENSE.

Эти условия описывают, что плагин AI Movie Company («плагин») делает на вашем компьютере и что
обещаете вы и его авторы. При первом запуске Эльза, режиссёр монтажа плагина, показывает короткую
выжимку и просит её принять. Пока вы не приняли, плагин ничего не устанавливает и ничего не
загружает и не публикует.

## 1. Что плагин делает на вашем компьютере

- Работает внутри Claude Code (вкладка Code в приложении Claude или терминал) на вашем Mac.
- **Читает** записи, субтитры и тексты, которые вы ему указали. Исходные файлы никогда не меняет.
- **Пишет** только: в папку проекта, которую вы выбрали (субтитры, списки фрагментов, готовые
  видео, обложки, отчёты); в `~/Movies/AI Movie Company/` (своя папка, отчёты для отзыва); в
  `~/Movies/CapCut/…` (новый проект CapCut — только по вашей просьбе); в `~/.ai_video_pipeline/`
  (настройки, знания о ваших выборах, журналы, дополнения для оформления); в свою папку данных
  внутри настроек Claude; в `~/.local/bin` (программы из списка ниже). Полный список — в README,
  «Что пишет на диск».
- Ведёт на вашем компьютере журнал того, что вы пишете Эльзе (секреты вырезаются), чтобы находить
  проблемы. Он никуда не уходит, если вы сами не отправите файл с отзывом.
- **Защищает компьютер от чужого кода**: любую команду, которая поставила бы программу не из
  собственного закреплённого списка плагина, — пакет из npm, PyPI, Homebrew и подобных, плагин для
  Claude, скрипт, скачанный и сразу запущенный, — плагин останавливает. Эльза объясняет, что это
  было, проверяет (имя, версию, возраст, известные инциденты) и запускает один раз и только если вы
  скажете «да». Проверку можно отключить явной настройкой (README, «Безопасность»).
- С вашего согласия может записать файл настроек **только в своей папке**
  (`~/Movies/AI Movie Company/.claude/settings.json`), чтобы Claude реже спрашивал разрешения там.
  Общие настройки Claude никогда не меняет. «Верни как было» всё отменяет.

## 2. Что ставит и откуда

При установке и когда вы просите обновление или дополнения для оформления — каждая программа
закреплена по версии и сверяется по контрольной сумме:

| Что | Откуда |
|---|---|
| Командная строка Claude | claude.ai (официальный установщик Anthropic) |
| uv и Python 3.13 | github.com (Astral) |
| ffmpeg и ffprobe 9.0.2 | ffmpeg.martin-riedl.de |
| Сам плагин | магазин `alexeykrol/plugins` на github.com |
| Пакеты Python для движка | pypi.org, список с хешами `requirements.lock` |
| Node.js 24 | nodejs.org |
| Chrome Headless Shell (рисование видео) | storage.googleapis.com (Google, Chrome for Testing) |
| Проект Remotion | registry.npmjs.org, закреплённый lock-файл, скрипты установки выключены |
| Плагин Remotion для Claude | каталог плагинов Anthropic, через командную строку Claude |

Python и ffmpeg, которые у вас уже есть, не трогаются. Ни пароль, ни права администратора не нужны.

## 3. Что отправляет в сеть

Сверено с кодом плагина 2026-11-19:

- **YouTube (Google)** — только когда проект загружает видео: приватные черновики, субтитры,
  обложки, плейлисты и публикация ровно того, что вы одобрили. Вход — на странице самого Google;
  плагин не видит ваш пароль; ключ доступа остаётся на вашем компьютере.
- **ElevenLabs** — голос и музыка для видео из текста идут через **ваш собственный** коннектор
  ElevenLabs в Claude, под вашим аккаунтом и по его условиям. Код плагина сам к ElevenLabs не
  обращается.
- **Источники установки** из раздела 2 — когда что-то ставится или обновляется.
- **Telegram** — только если вы сами включите уведомления в Telegram (по умолчанию выключено).
- Больше ничего: ни телеметрии, ни аналитики, ни рекламы, ни скрытых получателей. Телеметрия
  программ для анимации выключена, их локальные серверы слушают только ваш компьютер (127.0.0.1).

То, что вы показываете Claude в разговоре (субтитры, тексты, кадры, ваши сообщения), обрабатывает
Claude по **вашему соглашению с Anthropic**; плагин других получателей не добавляет.

## 4. Что обещают авторы

- Закреплённые и проверенные зависимости: точные версии, контрольные суммы или хеши, на момент
  закрепления не моложе 14 дней, скрипты установки выключены, где возможно; отчёты проверок лежат в
  исходном репозитории.
- Никакого скрытого сбора данных; список в разделе 3 полный для кода плагина.
- Публикация — только после вашего явного «ок» в диалоге; до того — приватные черновики.
- Адрес поддержки: **support@alexeykrol.com**.

## 6. Принять, отказаться, изменить

- Эльза показывает выжимку с тремя кнопками: «Принимаю», «Прочитать полностью» и «Не сейчас».
  Согласие — версия и дата — хранится на вашем компьютере в `~/.ai_video_pipeline/consent.json`.
  Никуда не отправляется.
- «Не сейчас»: Эльза может разговаривать и объяснять, но ничего не устанавливает и ничего не
  загружает и не публикует, пока вы не примете.
- Когда условия меняются, меняется версия, и Эльза спрашивает снова.
- Согласие можно отозвать в любой момент («отзови согласие с условиями»); установки и публикация
  останавливаются, пока вы не примете снова. Удаление плагина убирает его из Claude; ваши файлы
  остаются.
