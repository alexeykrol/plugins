# SIMovie — условия использования (закрытая альфа)

Версия: **2026-11-21-alpha1**

Полные условия использования: https://alexeykrol.com/elsa/terms/ · Политика конфиденциальности:
https://alexeykrol.com/elsa/privacy/

> Это перевод для удобства; действует английский текст ([TERMS.md](TERMS.md)).

SIMovie — плагин AI Movie Company с режиссёром монтажа Эльзой («плагин») — выпускает Алексей Крол
(Alexey Krol), физическое лицо (индивидуальный предприниматель) в штате Калифорния, США. Здесь
сказано, что плагин делает на вашем Mac, и коротко изложены условия альфы. При первом запуске Эльза
показывает короткую выжимку и просит её принять. **Принимая, вы принимаете эту страницу, полные
условия использования и политику конфиденциальности по ссылкам выше**; если эта страница и полные
условия расходятся, действуют полные условия. Пока вы не приняли, плагин ничего не устанавливает и
ничего не загружает и не публикует.

## 1. Что плагин делает на вашем Mac

- Работает внутри Claude Code (вкладка Code в приложении Claude или терминал) на вашем Mac.
- **Читает** записи, субтитры и тексты, которые вы ему указали. Устроен так, чтобы никогда не менять
  исходные файлы.
- **Пишет** только: в папку проекта, которую вы выбрали (субтитры, списки фрагментов, готовые
  видео, обложки, отчёты); в `~/Movies/AI Movie Company/` (своя папка, пакеты отзыва); в
  `~/Movies/CapCut/…` (новый проект CapCut — только по вашей просьбе); в `~/.ai_video_pipeline/`
  (настройки, знания о ваших выборах, журналы, дополнения для оформления); в свою папку данных
  внутри настроек Claude; в `~/.local/bin` (программы из списка ниже). Полный список — в README,
  «Что пишет на диск».
- Ведёт на вашем Mac журнал того, что вы пишете в сессиях с Эльзой (секреты вырезаются), чтобы
  находить проблемы. Он охватывает только сессии с Эльзой, остаётся на вашем Mac и уходит с него,
  только если вы сами отправите пакет отзыва.
- **Защищает Mac от чужого кода**: любую команду, которая поставила бы программу не из собственного
  закреплённого списка плагина, — пакет из npm, PyPI, Homebrew и подобных, плагин для Claude,
  скрипт, скачанный и сразу запущенный, — плагин останавливает. Эльза объясняет, что это было,
  проверяет (имя, версию, возраст, известные инциденты) и запускает один раз и только если вы скажете
  «да». Проверку можно отключить явной настройкой (README, «Безопасность»).
- С вашего согласия может записать файл настроек **только в своей папке**
  (`~/Movies/AI Movie Company/.claude/settings.json`), чтобы Claude реже спрашивал разрешения там.
  Общие настройки Claude никогда не меняет. «Верни как было» всё отменяет.

## 2. Что ставит и откуда

При установке и когда вы просите обновление или дополнения для оформления — каждая программа
закреплена по версии и сверяется по контрольной сумме:

| Что | Откуда |
|---|---|
| Командная строка Claude | claude.ai (официальный установщик Anthropic) |
| uv и Python 3.13 | github.com (Astral) |
| ffmpeg и ffprobe 9.0.2 | ffmpeg.martin-riedl.de |
| Сам плагин | магазин `alexeykrol/plugins` на github.com |
| Пакеты Python для движка | pypi.org, список с хешами `requirements.lock` |
| Node.js 24 | nodejs.org |
| Chrome Headless Shell (рисование видео) | storage.googleapis.com (Google, Chrome for Testing) |
| Проект Remotion | registry.npmjs.org, закреплённый lock-файл, скрипты установки выключены |
| Плагин Remotion для Claude | каталог плагинов Anthropic, через командную строку Claude |

Python и ffmpeg, которые у вас уже есть, не трогаются. Ни пароль, ни права администратора не нужны.

## 3. Что отправляет в сеть

- **Сервисы под вашими собственными аккаунтами и ключами** — только для задачи, которую вы поставили:
  - **YouTube (Google)** — только когда проект загружает видео: приватные черновики, субтитры,
    обложки, плейлисты и публикация ровно того, что вы одобрили. Вход — на странице самого Google;
    плагин не видит ваш пароль; ключ входа остаётся на вашем Mac.
  - **ElevenLabs** — текст для озвучки и описание музыки, только после того, как вы согласились с
    названной ценой; звук записи — только по вашему нажатию «Расшифровать». Через ваш собственный
    ключ или ваш коннектор ElevenLabs в Claude.
  - **Pexels, Pixabay** (готовые видео и фото) — слова поиска; **Google Gemini, OpenAI** (генерация
    картинок) — описания картинок. Только с вашим собственным ключом и по вашему запросу.
  - **Telegram** — уведомления, только если вы включите их со своим ботом.
  - **Anthropic (Claude)** — то, что вы показываете Claude в разговоре, обрабатывает Anthropic по
    вашему соглашению с Anthropic; плагин других получателей не добавляет.
- **Источники установки** из раздела 2 — когда что-то ставится или обновляется.
- **Техническая телеметрия нам** (`api.alexeykrol.com`) — **только после вашего согласия в
  плагине**: названия команд и шагов, длительности, типы ошибок, версии плагина и macOS, со случайным
  номером установки. Никогда — ваши диалоги, промпты, материал, пути к файлам и папкам, имена
  пользователей, тексты ошибок или заметки Эльзы. `vp telemetry show` показывает, что было бы
  отправлено; `vp telemetry off` выключает отправку в любой момент; `vp telemetry status` показывает
  номер установки (пришлите его нам, чтобы мы удалили вашу телеметрию).
- **Сообщения от нас** — по тому же адресу плагин спрашивает сообщения вроде «вышла новая версия».
  Эти запросы не хранятся вместе с вашим номером установки или IP.
- Больше ничего: ни аналитики, ни рекламы, ни скрытых получателей. Телеметрия программ для анимации
  выключена, их локальные серверы слушают только ваш Mac (127.0.0.1).

Всё остальное попадает к нам, только если вы сами это отправите: пакет отзыва (журнал ваших сессий с
Эльзой, заметки Эльзы, технические проверки), письмо или сообщение.

## 6. Принять, отказаться, изменить

- Эльза показывает выжимку с тремя кнопками: «Принимаю», «Прочитать полностью» и «Не сейчас».
  Согласие — версия и дата — хранится на вашем Mac в `~/.ai_video_pipeline/consent.json`. Никуда не
  отправляется.
- «Не сейчас»: Эльза может разговаривать и объяснять, но ничего не устанавливает и ничего не
  загружает и не публикует, пока вы не примете.
- Когда условия меняются, меняется версия, и Эльза спрашивает снова.
- Согласие можно отозвать в любой момент («отзови согласие с условиями»); установки и публикация
  останавливаются, пока вы не примете снова. Удаление плагина убирает его из Claude; ваши файлы
  остаются.
