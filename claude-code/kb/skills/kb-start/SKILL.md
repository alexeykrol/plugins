# /kb-start — проверка плагина с готовой базой

Тот, кто это вызвал, скорее всего только что поставил плагин и **не знает терминала**. Говори
с ним простым русским языком: без слов «терминал», «MCP», «CLI», «скилл», «JSON», без команд и
путей, если он сам о них не спросил. Команды запускаешь ты, а человеку рассказываешь, что
получилось. Каждая проверка — одна короткая строка: «✓ База на месте».

Собирать ничего не нужно: база «Теория каст и ролей» (20 записей) уже лежит внутри плагина.

**Где скрипт поиска.** Папка этого навыка — та, где лежит этот SKILL.md (Claude показывает её
как «Base directory for this skill»). Скрипт — в соседнем навыке:
`<папка этого навыка>/../kb-ask/scripts/search.py`. Ниже `S` — это

```
python3 "<папка этого навыка>/../kb-ask/scripts/search.py"
```

## Шаг 1. Навык поиска и база

Выполни `S --info`.

- **Напечатано «База «…»: N единиц … файл цел»** — «✓ База «Теория каст и ролей» на месте: N записей»
  (N — из вывода, сам не считай).
- **«файл ПОВРЕЖДЁН»** — скажи, что база в плагине повреждена и плагин стоит переустановить.
  Дальше не иди.
- **Команда не запустилась** — смотри, что в ответе:
  - есть `xcode-select`, `developer tools` или `Command Line Tools` — на Mac ещё нет
    инструментов разработчика Apple, и система открыла окно их установки. Скажи: «На экране
    должно было появиться окно с вопросом об установке инструментов разработчика. Нажмите
    „Установить“ и согласитесь с лицензией (5–20 минут). Потом полностью закройте Claude (⌘Q),
    откройте снова и ещё раз скажите „проверь плагин kb“». Дальше не иди.
  - `command not found` или старый Python (ниже 3.9) — «Нужен свежий Python с сайта python.org
    (кнопка Download); потом перезапустите Claude и снова скажите „проверь плагин kb“».
  - другое — передай последнюю строку ошибки и скажи, что плагин стоит переустановить.

## Шаг 2. Пример вопроса и ответа

Задай базе пример вопроса **«Как перейти из одной касты в другую»**: `S "Как перейти из одной касты в другую"`. Ответь человеку по форме
навыка kb-ask (`<папка этого навыка>/../kb-ask/SKILL.md`):
- прямой ответ в 1–3 предложениях;
- опора: строки `id · дата — «цитата»` (цитата — из строки «цитата:», не длиннее двух строк);
- если есть противоречия между записями — обе стороны с датами, без выбора победителя.

Если выдача пустая — это неисправность плагина (пример проверен при упаковке): перейди к итогу.

Добавь одну строку: «Так плагин отвечает по базе: с цитатами и с указанием, где записи спорят
друг с другом».

## Шаг 3. Дополнительные инструменты (не обязательны)

Посмотри на свой список инструментов: есть ли в нём `kb_search`, `kb_verdict` и другие `kb_*`
(в Code — примерно `mcp__plugin_kb_kb__kb_search`).

- **Есть** — «✓ Дополнительные инструменты подключены: плагин запомнит, какие ответы вы
  считаете верными».
- **Нет** — это **не ошибка**: отвечать по базе они не нужны. Скажи: «Отвечать по базе плагин
  может. Запоминать ваши решения о верности ответов в этом режиме он не будет». Если ты в
  Claude Code (есть доступ к файлам компьютера), можно проверить сервер:
  `python3 "<папка этого навыка>/../../server/kb-mcp" --selftest`. Напечатано
  `kb-mcp selftest OK` — значит, инструменты подхватятся после полного перезапуска Claude (⌘Q);
  так и скажи. В Chat этот шаг пропусти.

## Итог — одна фраза

- **База на месте, пример ответил:** «Плагин работает. Спрашивайте о том, что есть в базе
  „Теория каст и ролей“, — например: „Как перейти из одной касты в другую“».
- **Что-то не так** — одной-двумя фразами: что не работает (своими словами, без трейсбеков) и
  что сделать: установить инструменты разработчика, перезапустить Claude или переустановить
  плагин.

## Чего не делать
- Не показывать человеку команды, пути и сырой вывод, если он сам не попросил.
- Не ставить ничего самому (pip, brew) — только объяснять, что нажать.
- Не собирать базу и не трогать файлы базы — она поставляется готовой и только читается.
