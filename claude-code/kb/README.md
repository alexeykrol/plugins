# kb — книга «Теория каст и ролей» как база знаний для Claude

Плагин добавляет в Claude готовую базу знаний по книге Алексея Крола «Теория каст и ролей»
(12 глав). После установки Claude отвечает на вопросы **по книге**: называет главу, приводит
цитату и честно говорит, если ответа в книге нет. Ничего собирать и настраивать не нужно — база
уже внутри плагина.

Примеры вопросов:
- Как перейти из одной касты в другую?
- Чем отличаются роли Специалиста и Предпринимателя?
- Что автор говорит о пассивном доходе?

**Что нужно:** приложение Claude для компьютера (<https://claude.ai/download>) и платная
подписка Claude. В браузерной версии тоже можно (путь 1 ниже), но проверялось в приложении.

**Что плагин делает и чего не делает:** ищет по своей базе маленьким скриптом, который едет
вместе с ним. В интернет ничего не отправляет, ваших файлов не трогает. Единственное, что он
пишет, — ваши ответы «что верно» в папку `~/.kb/tcr-book/` на вашем компьютере.

## Установка

В приложении Claude есть три режима — вкладки **Chat**, **Cowork** и **Code**. Плагин в Chat и
Cowork ставится одним способом, в Code — другим. Если пользуетесь всеми — поставьте обоими.

> **Не просите Claude в чате «выполнить команды установки».** В чате у Claude свой временный
> облачный компьютер: плагин встанет туда и пропадёт после разговора.

### Путь 1. Chat и Cowork (обычный разговор с Claude)

1. В приложении Claude откройте меню слева и нажмите **Customize** (Настроить).
2. Выберите **Plugins** (Плагины).
3. Нажмите **Add** → **Add marketplace** (Добавить магазин).
4. Введите адрес магазина: `alexeykrol/plugins` и подтвердите.
5. **Пока магазин закрытый:** приложение попросит подключить GitHub (**Connect GitHub**) или
   установить **Claude GitHub App** — согласитесь и дайте доступ к репозиторию
   `alexeykrol/plugins`. Когда магазин станет открытым, этого шага не будет.
6. В списке плагинов магазина найдите **kb** и нажмите **Install** (Установить).
7. Начните **новый разговор** и напишите:

   ```
   проверь плагин kb
   ```

   Claude проверит, что база на месте, и покажет пример вопроса и ответа. Дальше просто
   задавайте вопросы о книге.

**Если магазин не добавляется** (такое бывает с закрытыми магазинами) — запасной путь: скачайте
файл навыка [`dist/kb-ask.zip`](dist/kb-ask.zip) (на странице файла — кнопка «Download raw
file»), затем в приложении **Customize → Skills → Upload** (Загрузить навык) и выберите этот
файл. Работать будет так же, только без проверки `проверь плагин kb`: сразу задавайте вопросы.

### Путь 2. Code (вкладка Code в приложении, терминал, VS Code)

Одна установка работает сразу во всех трёх местах.

1. Откройте вкладку **Code** в приложении Claude (или терминал, или Claude в VS Code).
   Создавая сессию во вкладке Code, выберите запуск **на этом компьютере (Local)**, а не в
   облаке (Cloud). В облачной сессии плагин встанет на временную машину и пропадёт вместе с ней.
2. Отправьте Claude этот текст:

   ```
   Установи плагин kb из магазина alexeykrol/plugins. Для этого выполни в терминале две команды:
   claude plugin marketplace add alexeykrol/plugins
   claude plugin install kb@krol
   Когда закончишь, скажи мне одной фразой, получилось ли, и что делать дальше.
   ```

   Claude попросит разрешение выполнить команды — нажмите **«Разрешить»**.
3. Начните **новую сессию** и напишите `проверь плагин kb`.

В терминале то же самое можно ввести самому:

```bash
claude plugin marketplace add alexeykrol/plugins
claude plugin install kb@krol
```

## Как пользоваться

Спрашивайте о книге своими словами. Если Claude сам не догадался заглянуть в базу, добавьте
«по книге» или «спроси базу»:

```
по книге: что такое функциональная роль?
```

Если книга говорит одно, а Claude «знает» другое, он покажет обе версии и спросит вас, какая
верна. В Code и Cowork ваш ответ запоминается; **в Chat — нет** (каждый разговор там
начинается в чистой песочнице).

В Code Claude может попросить разрешение запустить скрипт поиска плагина — это и есть поиск
по книге, разрешайте.

## Если что-то пошло не так

| Что видите | Что сделать |
|---|---|
| После установки Claude не знает про плагин | Начните **новый** разговор — плагин подключается в начале |
| Магазин не добавляется в Chat/Cowork | Подключите GitHub, когда приложение попросит, или используйте запасной путь с `kb-ask.zip` |
| В Code: окно «Установить инструменты разработчика» | Нажмите «Установить», дождитесь, повторите. Это нужно один раз |
| Claude отвечает «по памяти», без глав и цитат | Добавьте к вопросу «по книге» |

## Удалить

- Chat и Cowork: **Customize → Plugins** → kb → **Uninstall**.
- Code: напишите Claude `выполни claude plugin uninstall kb@krol`.
