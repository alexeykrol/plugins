# kb — база знаний из ваших документов

У вас есть папка с документами: заметки, статьи, договоры, конспекты. Плагин `kb` превращает её
в базу знаний, и Claude начинает отвечать **по вашим документам** — с указанием, из какого
документа ответ, с датой и цитатой. Если в ваших документах одно, а Claude «знает» другое, он
не выбирает молча, а спрашивает вас и запоминает ответ.

**Где хранится:** только у вас на компьютере, в папке `~/.kb/`. В интернет плагин ничего не
отправляет. Ваши документы он не меняет — только читает.

**Что читает:** `.md`, `.txt`, `.html`, `.docx`. PDF пока не читаются — плагин честно скажет,
какие файлы пропустил.

---

## Что нужно

- **Компьютер Mac.** На Windows пока не проверялось.
- **Приложение Claude для компьютера** — скачать: <https://claude.ai/download>.
- **Платная подписка Claude** (Pro или выше).

В браузерной версии Claude плагин не работает: ему нужен доступ к файлам на вашем компьютере.

---

## Установка — 5 минут

### Шаг 1. Откройте приложение Claude и вкладку «Code»

Запустите приложение Claude и войдите в свой аккаунт. Вверху окна переключитесь на вкладку
**Code**. Если приложение попросит выбрать папку для работы — выберите любую, например
«Документы».

### Шаг 2. Скопируйте этот текст и отправьте его Claude

```
Установи плагин kb из магазина alexeykrol/plugins. Для этого выполни в терминале две команды:
claude plugin marketplace add alexeykrol/plugins
claude plugin install kb@krol
Когда закончишь, скажи мне одной фразой, получилось ли, и что делать дальше.
```

Claude попросит разрешение выполнить команды — нажмите **«Разрешить»**.
Через полминуты он ответит, что плагин установлен.

### Шаг 3. Начните новый разговор

Плагин подключается при начале разговора. Откройте **новый разговор** (кнопка «+» или
«New session») во вкладке Code.

### Шаг 4. Проверьте, что всё работает

Напишите в новом разговоре:

```
проверь плагин kb
```

Claude соберёт маленькую учебную базу из трёх встроенных примеров, задаст ей вопрос и покажет
ответ с цитатами. В конце скажет: «Плагин работает». Это займёт 1–2 минуты.

Если Mac покажет окно «Установить инструменты разработчика» — нажмите **«Установить»**,
дождитесь окончания и снова напишите «проверь плагин kb». Это нужно один раз.

## Как пользоваться

### Собрать базу из своей папки

1. Найдите папку с документами в Finder.
2. Нажмите на неё правой кнопкой мыши, зажмите клавишу **Option** — в меню появится пункт
   **«Скопировать путь до …»**. Нажмите его.
3. Напишите Claude и вставьте путь:

```
собери базу из папки /Users/вы/Documents/Мои заметки
```

Claude покажет, сколько файлов войдёт и какие пропущены, и спросит **«Продолжать?»** — сборка
читает документы моделью и тратит лимит вашей подписки. Ответьте «да».

Начните с небольшой папки — 10–30 файлов. Сборка займёт несколько минут.

### Задавать вопросы

Просто спросите, упомянув базу:

```
по моей базе: что я писал о ценах на курс?
```

Claude ответит со ссылками на документы и цитатами. Если ответа в базе нет, он так и скажет.

### Если база расходится с тем, что знает Claude

Claude покажет обе версии и спросит, какая верна. Ваш ответ запоминается и в следующий раз
учитывается.

## Если что-то пошло не так

| Что видите | Что сделать |
|---|---|
| Claude пишет, что не может скачать магазин | Проверьте интернет. Если пишет про доступ к GitHub — сообщите автору |
| После установки Claude не знает про плагин | Начните **новый** разговор — плагин подключается только в начале |
| Окно «Установить инструменты разработчика» | Нажмите «Установить», дождитесь, повторите |
| «PDF пока не читаются» | Так и есть в этой версии. Сохраните нужные PDF как текст или Word |

## Удалить плагин

Напишите Claude: `удали плагин kb — выполни claude plugin uninstall kb@krol`.
Ваши базы останутся в папке `~/.kb/` — удалите её, если они больше не нужны.

## Для тех, кто работает в терминале

```bash
claude plugin marketplace add alexeykrol/plugins
claude plugin install kb@krol
```

Затем новый сеанс `claude` и фраза «проверь плагин kb».
