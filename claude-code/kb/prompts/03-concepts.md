# 03-concepts — понятия единиц (kb-reader, тот же проход)

## Задача
Для каждой единицы — 1–6 строк в секции `#concepts`: ключевые понятия, о которых она.

- **weight 2** — центральная тема единицы; **weight 1** — существенное упоминание.
- Понятие — именная группа 1–4 слова в нижнем регистре, без кавычек и точек
  («учёт вкладов», «память агента», «конфликт с моделью»), не предложение и не оценка.
- **Сначала — действующий словарь**: если подходящее понятие уже есть, используй его написание
  буква в букву. Новое понятие заводи только когда ни одно существующее не подходит, и тогда
  дай в поле definition одну строку определения (≤ 200 знаков). Для существующих definition пустой.
- Цель — компактный словарь корпуса (порядка 30–70 понятий на сотню документов): одно и то же
  явление — одно понятие; не плоди синонимы и узкие варианты («рефералка», «реферальная программа»
  — одно понятие).
- Для жанра noise понятий может не быть (0 строк).

## Контракт выхода (часть 2 из 2)
```
#concepts
id	concept	weight	definition
<id>	<понятие>	<1|2>	<определение нового понятия или пусто>
```
Ответ целиком — две секции подряд: `#units`, затем `#concepts`. Больше ничего.
