# 05-merge-vocab — слияние словаря понятий (хост или kb-tagger)

Код (`kbtool vocab-candidates`) нашёл пары похожих понятий: одинаковое написание с точностью до
ё/дефиса, опечатка, общие основы слов, одно входит в другое. Для каждой пары реши: это **одно и
то же явление** (слить) или разные (оставить).

- Сливай только синонимы, варианты написания и формы одного слова. Разные аспекты одной темы
  («учёт вкладов» и «модель учёта вкладов») — сливай, если корпус их не различает по смыслу.
- Каноническим делай более частое или более общее понятное написание.
- Понятия-одиночки (встречаются в одной единице) можно влить в близкое существующее понятие,
  если смысл не теряется.

Контракт выхода (`kbtool vocab-import -`):
```
#vocab-map
old	canonical
<понятие, которое исчезает>	<понятие, которое остаётся>
```
