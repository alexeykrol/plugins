# Плагины для Claude

Работают в приложении Claude (Chat, Cowork, Code), в терминале и в VS Code.
Каждый плагин — в своей папке, у каждого своя инструкция.

| Плагин | Для чего | Инструкция |
|---|---|---|
| **kb** — книга «Теория каст и ролей» | Claude отвечает по книге: глава, цитата, «в книге этого нет» | [kb](kb/README.md) |
